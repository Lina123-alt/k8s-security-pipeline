# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Report them privately
through GitHub:
https://github.com/Lina123-alt/k8s-security-pipeline/security/advisories/new

I will acknowledge a report within 7 days and aim to publish a fix within 30 days.

## Supported versions

Only the latest version on the `main` branch is supported.
